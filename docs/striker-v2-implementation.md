# RUNEKICK 공격수 v1.1 구현 기록

2026-10-27 · v1.1.0 구현·검증 완료. 배포 결과는 해당 GitHub 커밋의 Cloudflare 검사에서 확인합니다.

## 적용 범위

- 기술 카드 36종, 훈련 6종(36종에 포함), 휘발성 7종, 부상 3종. 장비 21종 재설계.
- 새 도전에 rulesVersion 2 적용. 기존 저장은 legacy-engine.js로 기존 도전 전체를 계속 진행. 새 도전을 시작해야 새 카드·장비 적용.
- 전투 중 버리기·뽑을 더미 선택·회수는 모달에서 선택 및 확정. 선택 도중에도 저장·복원 가능.
- 사용한 일반 카드는 즉시 버린 더미, 휘발성은 즉시 소멸 더미로 이동. played는 카드 사용 이력이며 실제 더미와 별도로 기록.
- 덱 부상과 전투 한정 부상 분리. 전투 한정 부상은 덱을 바꾸지 않음. 덱 부상은 ACT당 한 번 라커룸에서 한 장 치료하며 일반 강화/제거 대상에서 제외.
- 일반 카드 40장 제한과 부상 제한을 분리. 유물 획득 직후의 부상은 완료된 전투에 소급 적용하지 않음.
- 첫 일반 보상은 파워 슈팅/더블 터치/자리 선점. 일반 전투는 일반·특별, 엘리트는 희귀 1 + 특별 2. 보스는 빌드별 희귀 1장씩 제시.
- 상점 카드 70/150/320골드, 장비 90~140골드, 제거 50부터 +25. 기존 이벤트의 쉬운 희귀 획득은 특별 카드로 변경.
- ACT I 유소년 경로만 플레이 가능. ACT II·III 지도/상대/전환은 미구현. 유소년 최종 보스 보상 후 기존 완료 화면으로 종료.
- 호흡 정리는 다른 손패가 없을 때 바로 뽑기. 흐름 읽기는 뽑을 더미의 남은 최대 3장을 확인하며 버린 더미를 재혼합하지 않음.

## 검증

- 전체 Node 테스트 121개 통과. 기존 규칙 77개, 새 규칙/여정 38개, 새 튜토리얼 6개.
- 세 빌드 × 지도 시드 2/4/9 = 9회, 실제 시작 덱·보상·상점·훈련·보스 흐름을 자동 플레이하여 유소년 완주. 각 행동 후 저장 검사 통과. 이는 최종 체감 밸런스의 보장은 아님.
- 브라우저: 중간 선택 새로고침 복원, 상점 희귀 카드 구매, 라커룸 치료·장비 유지, 훈련 강화 비교, 기존 저장 바디 페인트 기세 +4 확인.
- 새 빌드 1.1.0을 별도 주소에서 캐시한 뒤 로컬 서버를 종료. 새로고침·카드 사용·재새로고침 후 방어 8/에너지 2 복원 확인.
- 320×568, 390×844 선택 모달 및 844×390 전투 레이아웃 점검. 실제 모바일 기기 성능 검증은 별도.
