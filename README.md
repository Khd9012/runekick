# RUNEKICK · 한 선수의 전설

선수 한 명의 기술 카드와 아이템을 조합하며 성장하는 도트 축구 덱빌딩 로그라이크입니다. v0.4 초안은 **나만의 선수 이름 → 개인 대결 → 카드/골드 보상 → 분기 지도·장비 파밍·레전드 도전 → 감독의 최종 시험**을 끝까지 플레이할 수 있습니다.

## 실행

Node.js 22 이상에서 추가 패키지 설치 없이 실행합니다.

```sh
npm run build
npm run dev
```

브라우저에서 http://127.0.0.1:4287/ 에 접속합니다. 서버 종료는 터미널에서 Ctrl+C. 다른 포트는 `node scripts/serve.mjs 4288`처럼 지정합니다.

```sh
npm test
```

정적 배포 시 `npm run build` 실행 후 `dist/`를 배포하면 됩니다. API, 로그인, 데이터베이스, 외부 폰트/이미지/CDN은 필요하지 않습니다. 원격 저장소 업로드와 외부 배포 설정은 별도로 진행합니다.

### Cloudflare Git 배포

Cloudflare Workers에서 `Khd9012/runekick` 저장소를 연결합니다. 프로젝트 이름은 `wrangler.jsonc`와 같은 `runekick`, 프로덕션 브랜치는 `main`, 루트 디렉터리는 `/`, 빌드 명령은 `npm run build`, 배포 명령은 `npx wrangler deploy`입니다. Node.js 22 이상을 사용합니다. `dist/`의 정적 파일만 배포하므로 서버 Worker 코드나 데이터베이스가 필요하지 않습니다.

Git 연동 후에는 `main`에 푸시하면 자동으로 빌드·배포됩니다. 로컬에서 직접 배포할 때는 Cloudflare 로그인 후 `npm run deploy`를 실행합니다. 앱의 저장 데이터는 브라우저 주소별로 분리되므로 localhost의 기존 도전이 공개 주소로 자동 이전되지는 않습니다.

## 전투 규칙

- 매 턴 에너지 3, 손패 5장으로 시작합니다. 아이템으로 늘릴 수 있습니다.
- 카드 선택 후 **카드 사용**을 누르면 즉시 효과가 적용됩니다. 상대 체력 0은 즉시 승리하며 반격하지 않습니다.
- 드리블로 쌓은 **기세**는 턴이 끝나도 유지됩니다. 슛은 기세를 모두 소비해 추가 피해를 줍니다.
- 상대 머리 위에는 다음 행동이 예고됩니다. **턴 종료** 시 방어를 뺀 피해가 내 체력에 적용됩니다. 방어는 다음 턴에 초기화됩니다.
- 내 체력은 대결 사이에도 유지됩니다. 휴식과 일부 아이템으로 회복합니다. 체력 0이면 도전이 끝납니다.
- 고정 턴 종료나 득점 비교는 없습니다. 장기전 방지를 위해 12턴 이후 상대 공격이 점점 강해집니다.
- PC: 숫자 1~9 카드 선택, Enter 사용, Space 턴 종료. 버튼에 포커스가 있을 때는 해당 버튼의 키보드 조작이 우선합니다.
- 모바일: 카드 터치 → 카드 사용. 손패는 가로 스크롤합니다. 지도·덱·아이템은 상단에서 확인합니다.

## 이번 초안의 콘텐츠

- 공격수 1명. 이름은 처음 시작할 때 정하고 라커룸이나 선수 이름을 눌러 변경합니다. 1~12자로 저장되며 덱과 진행 상황을 유지합니다.
- 일반 라이벌 3명, 엘리트 2명(레전드 파올로·드리블러 도윤), 감독 보스 7명. 기존 7단계 저장은 이전 에이스 보스를 유지합니다.
- 기술 카드 18종, 카드 강화와 제거, 보상 건너뛰기.
- 새 도전은 seed로 생성되는 12지점 전술 지도입니다. 실제 연결된 다음 지점으로만 이동합니다. 초반 일반전·훈련, 중반 상점·엘리트 선택, 마지막 회복·강화 후 감독 시험으로 이어집니다.
- 한 경로에 보스 포함 전투 4~6회, 엘리트 0~2회, 상점 0~2회가 배치됩니다. 엘리트와 상점에는 우회로가 있고 보스 직전 휴식/훈련 선택은 보장됩니다.
- 전투가 끝나면 카드 보상만 선택한 뒤 지도로 돌아옵니다. 회복·강화·구매는 해당 장소에 도착해야 가능합니다.
- 아이템 10종(상점 9종 + 레전드 전용 유물 1종). 상점은 4·7번째 단계의 지정 지점에 있고 미보유 아이템 4개를 제시합니다. 나간 상점으로는 돌아갈 수 없습니다.
- 파올로는 철벽/역습/빈틈의 3턴 패턴입니다. 철벽 턴의 첫 공격에는 체력 3 반격, 드리블은 상대 방어를 먼저 6 깎습니다. 희귀 카드가 보장되며 첫 승리에는 리베로의 증표(매 턴 첫 드리블 시 방어 +4)를 자동 획득합니다.
- 무리뉴·안첼로티·펩 과르디올라·아르테타·벵거·퍼거슨·클롭 중 한 명이 매 도전 최종 보스로 정해집니다. 지도에서 미리 전술을 확인할 수 있습니다. 보스 게이지는 전술 완성도를 나타내며, 이름 이외의 대사와 카드 전투 패턴은 게임을 위한 창작입니다.
- 승리 보상으로 골드를 모아 구입합니다. 아이템 효과는 부위 제한 없이 누적되며 같은 아이템은 중복 구매하지 않습니다.
- 축구화/훈련복/손목 밴드/양말/가방/보틀/동전/호루라기는 아이템 풀의 예시입니다. 고정 장착 슬롯은 없습니다.
- 큰 개인 캐릭터와 상대 행동 예고, 하단 손패·에너지·턴 종료, 갈림길 전술 지도.
- 화면은 차콜·짙은 네이비 UI와 채도를 낮춘 축구장 배경으로 구성합니다. 선수·감독·장비·경기장에 전용 AI 생성 도트 스타일 PNG 아트를 사용합니다. 무료 에셋 후보 비교와 최종 프롬프트는 `ART_SOURCES.md`에 기록했습니다. 유료 에셋을 구매하지 않았습니다.
- 프로 리그·유럽대항전, 미드필더·수비수, 영구 캐릭터 해금은 후속 범위입니다.

## 저장과 오프라인

카드 사용, 턴 종료, 보상·노드 선택과 구매마다 브라우저 localStorage에 저장합니다. 난수 상태와 카드 순서가 유지되어 다시 접속해 이어할 수 있습니다. 여러 창에서 동시에 진행하면 오래된 창의 저장을 중단하고 새로고침 안내를 표시합니다.

첫 접속 후 서비스 워커 설치가 완료되면 오프라인 실행과 새로고침을 지원합니다. 브라우저에서 사이트 데이터를 삭제하면 기록과 오프라인 캐시도 사라집니다. 기기 간 동기화는 없습니다.

새 버전은 기존 게임 탭을 모두 닫은 후 활성화됩니다. `npm run build`는 실제 파일 내용에 따라 서비스 워커 캐시 버전을 자동 생성합니다. 초기 팀 경기 초안의 저장은 별도 키로 보존하며 개인 대결 버전에 이관하지 않습니다. 개인 대결 schema2의 7단계 경로는 그대로 이어갑니다. v0.2에서 삭제된 앞/뒤 상점 기록도 구매 내역을 보존하여 복구됩니다. 새 지도와 감독 보스는 새 도전부터 적용됩니다.

중간 개발 버전이 예전 상점 저장을 백업하고 새 도전을 시작한 경우에는 메뉴의 **이전 지도에서 하던 도전**으로 복원할 수 있습니다. 복원 전 현재 도전도 별도 키에 보관합니다.

## 파일 구조

- `dist/engine.js`: 결정론적 순수 전투/경로/아이템 규칙, 저장 검증.
- `dist/app.js`: UI, 사운드, 저장, 입력.
- `dist/art.js`: 전용 선수·감독·장비·경기장 아트 로딩과 전투 연출.
- `dist/assets/`: 오프라인 캐시에 포함되는 로컬 PNG 에셋.
- `dist/styles.css`: 데스크톱/모바일 전투 화면.
- `scripts/build.mjs`: 모듈 구문과 파일 검사, 오프라인 캐시 생성.
- `scripts/serve.mjs`: 로컬 정적 서버.
- `tests/engine.test.js`: 즉시 피해, 기세, 방어, 아이템 누적, 구매, 분기, 승패, 저장 복구와 전체 도전 검증.

수치와 상대 패턴은 프로토타입 밸런스입니다. 모바일 크기의 브라우저 화면은 확인하되 실제 Android/iOS 기기 성능 검증과 최종 밸런스 조정은 별도입니다.
