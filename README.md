# RUNEKICK · 한 선수의 전설

선수 한 명의 기술 카드와 아이템을 조합하며 성장하는 도트 축구 덱빌딩 로그라이크입니다. v1.0 초안은 **나만의 선수 이름 → 연습 튜토리얼·시작 장비 선택 → 개인 대결 → 카드/골드 보상 → 분기 지도·장비 파밍·레전드 도전 → 감독의 최종 시험**을 끝까지 플레이할 수 있습니다.

## 실행

Node.js 22 이상에서 추가 패키지 설치 없이 실행합니다.

```sh
npm run build
npm run dev
```

브라우저에서 http://127.0.0.1:4287/ 에 접속합니다. 서버 종료는 터미널에서 Ctrl+C. 다른 포트는 `node scripts/serve.mjs 4288`처럼 지정합니다.

```sh
npm test
```

정적 배포 시 `npm run build` 실행 후 `dist/`를 배포하면 됩니다. API, 로그인, 데이터베이스, 외부 폰트/이미지/CDN은 필요하지 않습니다. 원격 저장소 업로드와 외부 배포 설정은 별도로 진행합니다.

### Cloudflare Git 배포

Cloudflare Workers에서 `Khd9012/runekick` 저장소를 연결합니다. 프로젝트 이름은 `wrangler.jsonc`와 같은 `runekick`, 프로덕션 브랜치는 `main`, 루트 디렉터리는 `/`, 빌드 명령은 `npm run build`, 배포 명령은 `npx wrangler deploy`입니다. Node.js 22 이상을 사용합니다. `dist/`의 정적 파일만 배포하므로 서버 Worker 코드나 데이터베이스가 필요하지 않습니다.

Git 연동 후에는 `main`에 푸시하면 자동으로 빌드·배포됩니다. 로컬에서 직접 배포할 때는 Cloudflare 로그인 후 `npm run deploy`를 실행합니다. 앱의 저장 데이터는 브라우저 주소별로 분리되므로 localhost의 기존 도전이 공개 주소로 자동 이전되지는 않습니다.

## 튜토리얼

처음 시작해 이름을 정하면 튜토리얼 소개가 나옵니다. 별도 연습 경기에서 카드 선택·사용, 드리블로 기세 모으기, 슈팅으로 기세 소비, 방어와 턴 종료를 직접 익힙니다. 마지막에는 카드 보상과 지도 속 훈련장·라커룸·상점을 안내합니다.

소개와 진행 중 언제든 **튜토리얼 건너뛰기**를 누르면 튜토리얼 전체가 종료되고 원래 게임으로 돌아갑니다. Escape도 같은 동작입니다. 완료하거나 건너뛴 뒤에는 자동으로 다시 열리지 않으며, 게임 메뉴 또는 플레이 방법의 **튜토리얼**에서 다시 시작할 수 있습니다. 진행 도중 창을 닫았다면 재접속 시 소개부터 다시 시작하거나 건너뛸 수 있습니다.

연습 경기의 체력·골드·덱·경로·난수는 실제 도전과 분리됩니다. 완료하면 **번개 스터드(슈팅 피해 +3), 바람의 축구화(드리블 기세 +1), 익숙한 훈련복(매 턴 시작 방어 3)** 중 장비 하나를 무료로 고릅니다. 선택한 장비만 실제 도전에 적용됩니다. 건너뛰면 보상을 받지 않으며, 다시 완료하더라도 같은 도전에서 중복 지급되지 않습니다. 미선택 보상은 저장되어 새로고침하거나 메뉴의 **시작 장비 받기**로 이어서 고를 수 있습니다. 기존 사용자의 도전에는 자동으로 끼어들지 않습니다. 튜토리얼 표시 여부만 별도 브라우저 설정에 저장하며 오프라인에서도 사용할 수 있습니다.

## 전투 규칙

- 매 턴 에너지 3, 손패 5장으로 시작합니다. 아이템으로 늘릴 수 있습니다.
- 카드 선택 후 **카드 사용**을 누르면 즉시 효과가 적용됩니다. 상대 체력 0은 즉시 승리하며 반격하지 않습니다.
- 드리블로 쌓은 **기세**는 턴이 끝나도 유지됩니다. 슛은 기세를 모두 소비해 추가 피해를 줍니다. 닉네임은 선수 위에 표시하고, 발 아래 체력바 밑에는 **하늘색 방패 + 방어 수치 / 노란 번개 + 기세 수치**만 작게 표시합니다. 상대 방어도 같은 방패와 숫자로 표시합니다. 배경 박스 없이 아이콘을 누르면 각 대상의 현재 수치와 적용 방식을 설명하는 창이 열립니다. 기세가 쌓이면 선수 주변 금빛 기운이 강해집니다.
- 상대 머리 위에는 다음 행동이 예고됩니다. **턴 종료** 시 방어를 뺀 피해가 내 체력에 적용됩니다. 방어는 다음 턴에 초기화됩니다.
- 내 체력은 대결 사이에도 유지됩니다. 휴식과 일부 아이템으로 회복합니다. 체력 0이면 도전이 끝납니다.
- 고정 턴 종료나 득점 비교는 없습니다. 장기전 방지를 위해 12턴 이후 상대 공격이 점점 강해집니다.
- PC: 숫자 1~9 카드 선택, Enter 사용, Space 턴 종료. 버튼에 포커스가 있을 때는 해당 버튼의 키보드 조작이 우선합니다.
- 모바일: 최대 6장의 손패를 겹쳐 표시하고 선택한 카드는 확대합니다. 카드 또는 아래 이름 버튼으로 바로 선택하며 가로 스크롤은 필요 없습니다. 에너지·카드 사용·턴 종료는 화면 하단에 고정됩니다. 작은 화면에서는 세로로 이동할 수 있고 지도·덱·아이템 창은 따로 열립니다.
- 카드 바탕색으로 **공격(빨강) / 수비(파랑) / 기술(초록)**을 구분합니다. 슈팅·터치는 공격, 방어는 수비, 드리블·전술은 기술입니다. 카드의 드리블·슈팅 표시는 유물 효과의 적용 대상을 알려줍니다.
- 카드 왼쪽 위 원은 에너지 비용, 본문 큰 숫자는 기본 피해·방어·에너지입니다. 부가 효과는 아래에 표시하며, 선택 후 상대 방어와 기세를 반영한 실제 예상 결과를 손패 위에서 확인합니다.
- 24종의 카드는 고유 실루엣 동작 일러스트를 사용합니다. PC 카드 폭은 196px, 모바일 선택 카드는 170px이며 좁은 화면과 가로 모드에서는 조작부를 하단 고정합니다.
- 지도에는 훈련장·라커룸·입단 테스트 제의가 등장합니다. 초반 상점은 동네 스포츠점, 후반은 도전마다 시내 스포츠점·시내 쇼핑센터·백화점 스포츠관 중 하나로 표시됩니다. 장소 이름은 기존 저장에도 반영되며 상점 수·가격·경로는 유지합니다.

## 디버프 카드

약점 노출과 공격 약화는 상대 방어 옆에 작은 아이콘과 남은 턴으로 표시합니다. 아이콘을 누르면 현재 효과와 지속 시간을 확인합니다. 기본 덱은 유지하며 아래 6종은 전투 카드 보상에서 획득하고 훈련장에서 강화할 수 있습니다.

| 카드 | 종류 / 비용 | 기본 효과 | 강화 후 |
| --- | --- | --- | --- |
| 빈틈 포착 | 기술 / 1 | 약점 노출 2턴 | 3턴 |
| 유인 드리블 | 기술·드리블 / 1 | 약점 노출 1턴, 기세 +3 | 노출 2턴, 기세 +4 |
| 흔드는 슈팅 | 공격·슈팅 / 1 | 피해 6 후 약점 노출 1턴, 기세 모두 소모해 추가 피해 | 피해 9, 노출 2턴 |
| 전방 압박 | 기술 / 1 | 공격 약화 2턴 | 3턴 |
| 견제 태클 | 수비 / 1 | 방어 +5, 공격 약화 1턴 | 방어 +8, 약화 2턴 |
| 집요한 마크 | 공격·터치 / 1 | 피해 5 후 공격 약화 1턴 | 피해 8, 약화 2턴 |

- **약점 노출**: 카드 피해를 50% 늘린 뒤 소수점을 버리고 상대 방어를 적용합니다. 기세·장비 보너스를 포함하지만, 방어를 무시하지는 않습니다.
- **공격 약화**: 상대의 다음 공격을 25% 줄인 뒤 소수점을 버리고 내 방어를 적용합니다. 반사 피해와 카드의 체력 소모에는 적용되지 않습니다. 상대 행동 예고와 피해 예상도 감소한 수치로 표시합니다.
- 숫자는 강도가 아닌 **남은 턴**입니다. 중복 적용하면 지속 시간만 합산하며 최대 99턴, 피해 증감 비율은 동일합니다. 이번 턴을 포함하고 상대 반격이 끝날 때 1턴 줄어듭니다. 1턴 약점 노출은 이번 턴의 남은 카드에, 1턴 공격 약화는 이번 반격에 적용됩니다.
- 공격과 디버프를 함께 주는 카드는 **피해 → 디버프** 순서입니다. 그 카드가 새로 건 약점은 같은 카드의 피해를 늘리지 않습니다. 이미 걸려 있던 약점은 적용됩니다.
- 효과는 해당 대결에서만 유지됩니다. 진행 중 저장·재접속해도 남은 턴을 보존하고, 이전 저장에 없던 상태 값은 0으로 복원합니다.

## 이번 초안의 콘텐츠

- 공격수 1명. 이름은 처음 시작할 때 정하고 라커룸이나 선수 이름을 눌러 변경합니다. 1~12자로 저장되며 덱과 진행 상황을 유지합니다.
- 일반 라이벌 3명, 엘리트 4명(파올로 말디니·지네딘 지단·호나우두·도윤), 감독 보스 7명. 기존 7단계 저장은 이전 에이스 보스를 유지합니다.
- 기술 카드 24종, 카드 강화와 제거, 보상 건너뛰기. 훈련장 목록도 실제 카드 모습으로 표시합니다. 훈련장의 강화 버튼은 현재/강화 후 카드와 에너지·피해·방어·기세·디버프 지속 시간 등 수치표를 먼저 보여주며, 확정할 때 한 장만 강화합니다.
- 새 도전은 seed로 생성되는 12지점 전술 지도입니다. 실제 연결된 다음 지점으로만 이동합니다. 초반 일반전·훈련, 중반 상점·엘리트 선택, 마지막 회복·강화 후 감독 시험으로 이어집니다.
- 한 경로에 보스 포함 전투 4~6회, 엘리트 0~2회, 상점 0~2회가 배치됩니다. 엘리트와 상점에는 우회로가 있고 보스 직전 휴식/훈련 선택은 보장됩니다.
- 일반 전투 후에는 전투 화면 위에 뜨는 카드 보상 창에서 3장을 비교하고, 한 장의 상세 효과를 확인한 뒤 확정하면 지도로 돌아옵니다. 모바일에서도 세 장이 동시에 보이며 가로 스크롤 없이 선택합니다. 창을 닫으면 미수령 상태로 보관되며 카드 보상 고르기로 다시 열 수 있습니다. 엘리트전은 전용 유물 하나를 먼저 선택하고 카드 보상을 받습니다. 회복·강화·구매는 해당 장소에 도착해야 가능합니다.
- 상점에서 카드를 선택하고 확인한 뒤 제거할 수 있습니다. 첫 제거 50골드, 이후 75·100골드처럼 매번 25골드씩 증가하며 같은 도전의 다음 상점에도 이어집니다. 새 도전에서는 초기화되고 훈련장의 무료 제거는 가격에 영향을 주지 않습니다. 상점 제거 후 마지막 카드 1장은 유지합니다.
- 아이템 21종(상점 9종 + 엘리트 전용 유물 12종). 상점은 4·7번째 단계의 지정 지점에 있고 미보유 아이템 4개를 제시합니다. 나간 상점으로는 돌아갈 수 없습니다.
- 말디니는 철벽/역습/빈틈의 3턴 패턴입니다. 철벽 턴에 처음 피해를 주는 카드에는 체력 3 반격, 드리블은 상대 방어를 먼저 6 깎습니다. 지단은 높은 방어와 점점 강해지는 연계, 호나우두는 강공 예고와 낮은 방어, 도윤은 드리블 압박이 특징입니다. 엘리트 승리 시 희귀 카드가 포함된 보상과 해당 선수 전용 유물 3개 중 하나를 선택합니다. 이미 보유한 유물은 제외하며 전용 유물은 상점에 나오지 않습니다.
- 무리뉴·안첼로티·펩 과르디올라·아르테타·벵거·퍼거슨·클롭 중 한 명이 매 도전 최종 보스로 정해집니다. 지도에서 미리 전술을 확인할 수 있습니다. 보스 게이지는 전술 완성도를 나타내며, 이름 이외의 대사와 카드 전투 패턴은 게임을 위한 창작입니다.
- 승리 보상으로 골드를 모아 구입합니다. 아이템 효과는 부위 제한 없이 누적되며 같은 아이템은 중복 구매하지 않습니다.
- 축구화/훈련복/손목 밴드/양말/가방/보틀/동전/호루라기는 아이템 풀의 예시입니다. 고정 장착 슬롯은 없습니다.
- 큰 개인 캐릭터와 상대 행동 예고, 하단 손패·에너지·턴 종료, 갈림길 전술 지도. 기본 선수는 짧은 머리·등번호 유니폼·긴 양말·축구화·일반 축구공을 사용하는 축구 선수 모습입니다.
- 상점에는 다니엘 레비를 모티브로 한 도트 상인이 장부와 축구 장비 카운터로 손님을 맞이합니다. 상인 대사는 게임을 위한 창작이며, 상품 구매·카드 제거 규칙은 동일합니다.
- 화면은 차콜·짙은 네이비 UI와 채도를 낮춘 축구장 배경으로 구성합니다. 선수·감독·장비·경기장에 전용 AI 생성 도트 스타일 PNG 아트를 사용합니다. 무료 에셋 후보 비교와 최종 프롬프트는 `ART_SOURCES.md`에 기록했습니다. 유료 에셋을 구매하지 않았습니다.
- 프로 리그·유럽대항전, 미드필더·수비수, 영구 캐릭터 해금은 후속 범위입니다.

## 감독 보스와 전투 연출

새로 시작하는 감독전에는 감독마다 다른 전술 조건이 적용됩니다. 전술 안내에 다음 행동, 진행 상태와 대응 조건을 표시하며, 공격 약화를 포함한 실제 공격력이 피해 예고에 반영됩니다.

| 감독 | 전술과 대응 | 전술 연출 |
| --- | --- | --- |
| 무리뉴 | 남은 수비벽을 다음 역습에 사용. 준비 중 방어를 깎아 역습을 줄입니다. | 하늘색 수비벽과 역습 화살표 |
| 펩 과르디올라 | 압박이 쌓이면 강공. 한 턴에 공격·수비·기술을 모두 사용해 압박을 풉니다. | 좁혀오는 압박선과 패스 연결망 |
| 클롭 | 압박 중 첫 기술에 체력 소모. 압박 뒤 회복 턴에는 공격 기회가 생깁니다. | 붉은 압박 궤적과 회복 때 풀리는 선 |
| 안첼로티 | 직전 턴에 가장 많이 사용한 카드 종류에 대응하는 태세를 선택합니다. | 태세에 따라 달라지는 전술 화살표 |

| 벵거 | 이어지는 연계로 공격 강화. 한 턴에 피해를 주는 카드를 세 번 사용하면 연계를 끊습니다. | 이어지는 패스 지점과 끊어지는 연결선 |

공격에는 공의 궤적·접촉 불꽃·피격 반응과 피해 숫자를, 방어에는 하늘색 방패 충격과 방어량을 표시합니다. 큰 피해일수록 타격 연출이 강해지고, 방어에 막힌 피해와 실제 체력 피해를 구분합니다. 소리는 기존 소리 설정을 켠 경우에만 재생합니다. 모션 줄이기 설정에서는 흔들림과 이동 연출을 줄이고 숫자와 전술 안내를 유지합니다.

업데이트 전에 이미 진행 중이던 감독전은 저장된 기존 패턴으로 마무리합니다. 해당 전투의 체력·손패·다음 공격을 바꾸지 않으며, 다음에 새로 시작하는 감독전부터 새 전술이 적용됩니다.

## 저장과 오프라인

카드 사용, 턴 종료, 보상·노드 선택과 구매마다 브라우저 localStorage에 저장합니다. 난수 상태와 카드 순서가 유지되어 다시 접속해 이어할 수 있습니다. 여러 창에서 동시에 진행하면 오래된 창의 저장을 중단하고 새로고침 안내를 표시합니다.

첫 접속 후 서비스 워커 설치가 완료되면 오프라인 실행과 새로고침을 지원합니다. 브라우저에서 사이트 데이터를 삭제하면 기록과 오프라인 캐시도 사라집니다. 기기 간 동기화는 없습니다.

새 버전은 기존 게임 탭을 모두 닫은 후 활성화됩니다. `npm run build`는 실제 파일 내용에 따라 서비스 워커 캐시 버전을 자동 생성합니다. 초기 팀 경기 초안의 저장은 별도 키로 보존하며 개인 대결 버전에 이관하지 않습니다. 개인 대결 schema2의 7단계 경로는 그대로 이어갑니다. v0.2에서 삭제된 앞/뒤 상점 기록도 구매 내역을 보존하여 복구됩니다. 새 지도와 감독 보스는 새 도전부터 적용됩니다. v0.7은 새 지도 버전(routeVersion 2)에서 엘리트 4명 중 첫 지점 1명과 후반 지점의 다른 2명을 배치합니다. 이전 12지점 저장은 버전1의 상대·분기·난수·보유 유물을 유지합니다. 이전 버전에서 이미 지급된 리베로의 증표도 보존합니다.

중간 개발 버전이 예전 상점 저장을 백업하고 새 도전을 시작한 경우에는 메뉴의 **이전 지도에서 하던 도전**으로 복원할 수 있습니다. 복원 전 현재 도전도 별도 키에 보관합니다.
